# Contributing
Open an issue describing the user-visible problem before a large change.
Read docs/ARCHITECTURE.md and docs/ENGINEERING.md, then inspect affected code and tests.
Use synthetic data only. Include a focused regression and preserve source ownership, opaque references,
source-set versions, cancellation/replay, Todo hierarchy and stable error contracts.
Contributions are offered under AGPL-3.0-only; third-party work must retain its notices.
Maintainers review changes in their main development line and synchronize reviewed community updates.
The public CI cannot deploy any hosted production instance.
